# 作者指南

从新建教程或导入 Markdown 开始。二级标题转换为步骤，围栏代码里的标题不会被误拆。导入仅生成草稿，默认人工确认条件需由作者填写。

1. 填写标题、简介、内容版本及环境字段。
2. 编写操作说明，选择前置依赖，设置是否允许跳过。
3. 为每步配置至少一个必需检查点，明确检查范围。
4. 配置排错问题、修复建议和结束节点。为未知症状保留出口。
5. 查看流程预览，修复底部校验问题。
6. 试走教程，再保存和导出教程包。

修改教程不会更新已有会话。发布新版时主动递增内容版本，以便统计分开比较。

在报告页把当前报告加入作者分析，或导入学习者的 JSON 报告。相同会话 ID 后导入的记录替换先前记录，避免重复统计。不同版本按独立步骤行统计。
