# 架构

React + TypeScript + Vite，Dexie/IndexedDB 持久化，Zod 校验教程包，unified/remark-parse 识别 Markdown 语法，react-markdown 安全渲染，semver 检查版本，Vitest 验证核心规则。

规则位于 core，不依赖 React。UI 对状态进行不可变更新，存储通过 Promise 队列串行写入，避免旧保存覆盖新保存。会话创建时深拷贝教程并固定版本。进度用于恢复现场，事件保留失败、重试、症状和修复尝试。

改变已检查的输入会撤销该检查并使所有下游步骤过期。下游必须重新提交所有必需检查点。依赖可操作状态与检查完成状态分别计算。

统计按会话 ID 去重；失败比例按出现失败的会话计，平均检查次数按检查点提交数计。排错后通过指标仅统计进入排错后再次检查符合条件的会话，不证明因果。

未结束的会话不推断为放弃，不计算关闭网页后的学习时长。
