# 当前限制

- 无账号、云同步、自动命令执行或本地文件探测。
- 检查仅验证提交文本与用户声明，不证明整个软件系统正常。
- IndexedDB 数据依赖当前浏览器；隐私模式、存储空间或权限可能导致保存失败，UI 会提示导出备份。
- Markdown 不支持原始 HTML 或本地图片打包。外部图片若在正文中引用，会发起外部请求。
- 版本检查需要指定前缀及三段版本号，不在任意日志中猜测版本。
- 编辑器采用表单和结构化流程预览，没有拖拽图编辑器。
- 暂无 CLI、AI 创作、报告跨设备同步或学习时长估算。
- 自动化浏览器测试使用已安装的 Microsoft Edge。其他浏览器与线上静态部署需要单独验证。
